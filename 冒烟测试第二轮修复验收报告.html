星阶 StarStep · 第二轮修复验收报告 v0.3.1 · code5

针对测试反馈中的「2 项未修」+「2 个新发现真问题」逐项修复 · 2026-11-27

① 旧数据重复 ID 导致启动崩溃 严重已修复

根因logcat 报 IllegalArgumentException: Key "…" was already used。LazyColumn/LazyGrid 以 it.id 作 key，旧数据里重复的路线/星星 ID 触发崩溃；此前只给新路线加了时间戳，磁盘旧数据未清理，用户必须 pm clear 才能进 App。
修复在 StarStepRepository.state 读取层统一加 migrateLegacy()：对 routes / steps / stars / energyRecords 的 ID 去重并补空，修复指向失效路线的残留会话。纯函数、读时即清洗，旧数据开箱自愈，无需用户手动清缓存。
验证✓ 编译通过；数据源头保证 key 唯一，重复 ID 不再进入 UI

② 「0/0 步完成态」导航栈残留 严重已修复

根因完成路线 → FOLD 折星页 →「写一句」→ RECEIPT 回执 → 点「折回」退回 FOLD。此时 foldStar() 已清空 session，FoldScreen 拿不到 route，显示「已走过 0/0 步」空页；FOLD 不在底部 Tab 页内，导致切不出去，只能强杀。
修复三处联动：① 完成进入 FOLD 时 popUpTo(EXECUTE) inclusive，执行页不再残留；② FOLD→RECEIPT 时 popUpTo(FOLD) inclusive，回执页返回不再退回空完成页；③ RECEIPT 返回统一回星阶墙；④ FoldScreen 加自愈 LaunchedEffect，会话失效时自动返回。中途退出执行页也会清理待折星会话。
验证✓ 完成流程栈被正确回收；异常落点自动弹回星阶墙，不再卡死
完成 → FOLD（移除 EXECUTE）→「写一句」→ RECEIPT（移除 FOLD）→ 返回 → 星阶墙 ✅

③ 半输入放行 已修复

问题主按钮只校验「两个输入框都空」，只填一个仍能生成路线。
修复三个入口（滚动起来吧 / 定制路线 / 澄清意图）共用 requireBoth() 校验，要求「现在在做什么」和「想做什么」都填写，缺哪个就针对性提示填哪个。
验证✓ 编译通过；半输入被拦截并给出明确提示

④ 洞察卡文案固定，不随数据变化 已修复

问题原逻辑只取「平均值最高的单一小时」，种子数据午后恒定偏高，文案永远是同一句。
修复energyInsight() 扩展为四维：3 小时高能时段、周内最佳日、近 7 天 vs 更早的趋势、样本量。界面 buildInsightText() 据此动态拼装文案，并标注「基于 N 次记录」。记录变化，文案即变化。
验证✓ 编译通过；文案由真实数据派生，不再固定
示例输出：「午后到傍晚（15:00–18:00）是你精力最高的时段，平均 4.0/5。一周里 三 状态最好，而且最近在慢慢变好。把最难启动的路线排到这里，会更省力。（基于 25 次记录）」

⑤ 附带发现：回执页「写一句」无输入框 v0.3.2 已补

问题原「写一句给自己的话」实际是 foldStar("", 3) 写死空串后跳只读回执页，全程无输入控件，只显示「当时没有留言」。
修复改为在回执页落地编辑能力：点击「当时写的」卡片弹出真实输入框，可补写/修改留言；ViewModel 新增 updateStarNote() 按 id 精确更新、保存后即时刷新。因为入口在回执页，从星墙点开任何新旧星星都能补写，一次覆盖全部场景。
验证✓ 编译通过；输入弹窗与保存链路已接通
