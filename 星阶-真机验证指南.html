先把 APK 拿到你的电脑上

沙箱和你的电脑是两套独立环境。在上方对话的交付物卡片里，点击 星阶-app-debug.apk 下载到本地（Windows 常见落在 下载 文件夹）。文件名带中文，若传输工具不兼容可重命名为 xingjie.apk。

校验完整性：下载后文件应为 17 MB，MD5 为 1f7ef1412316ce1df21a750ed89f5310。Windows 可用 PowerShell 运行 Get-FileHash 文件名 -Algorithm MD5 核对。

选一种安装方式

三种方式按推荐度排列。只想快速看效果用真机直装；不想用手机就用电脑模拟器。

最推荐

A · 真机直接安装

约 5 分钟 · 效果最真实
  1. 把 APK 传到手机：数据线拷贝，或用微信/QQ「文件传输助手」发给自己后在手机保存。
  2. 手机打开文件管理器，找到 APK 点击安装。
  3. 系统提示「未知来源」时，选择允许本次安装。
  4. 桌面出现「星阶」图标，点击打开。
小米/华为/OPPO 若被「纯净模式」拦截：设置 → 安全 → 关闭纯净模式 / 允许安装未知应用。

B · 电脑模拟器

不用手机 · 适合演示
  1. 下载国内模拟器（MuMu、雷电、夜神任一），安装并启动。
  2. 把 APK 直接拖进模拟器窗口，或点模拟器里的「导入/安装 APK」。
  3. 自动安装后，桌面出现「星阶」图标。
  4. 建议模拟器设置：Android 9 以上、4GB 内存、竖屏。
或用 Android Studio → Device Manager 创建 AVD（Pixel 7 / Android 14），把 APK 拖进模拟器即可。

C · ADB 命令行

开发者方式 · 需数据线
  1. 手机：设置 → 关于手机 → 连点「版本号」7 次开启开发者选项。
  2. 开发者选项里打开USB 调试，数据线连电脑并允许授权。
  3. 电脑装 adb（或 Android Studio 自带），执行右侧命令。
  4. 出现 Success 即安装成功。
adb devices
adb install 星阶-app-debug.apk

常见问题

安装时提示「解析包错误」

三种原因：① 手机系统低于 Android 8.0（本 App 最低 8.0）；② 下载不完整，重新下载并核对 MD5；③ 文件名含特殊字符，重命名为 xingjie.apk 再装。

装完打不开 / 一闪就退回桌面

先确认系统版本 ≥ 8.0。若是 Android 14+ 且装到一半卡住，检查存储空间。可连电脑执行 adb logcat 抓日志发我，我帮你定位。

语音播报没声音

检查手机媒体音量与「应用通知/后台弹出」权限。语音用系统 TTS，若中文 TTS 缺失会静默——这是真机环境差异，不影响其他功能。

桌面找不到图标

到应用抽屉搜索「星阶」。部分桌面需下拉刷新或重启。ADB 可用 adb shell monkey -p com.starstep.app -c android.intent.category.LAUNCHER 1 直接拉起。

想卸载重装（恢复种子数据）

设置 → 应用管理 → 星阶 → 卸载；或在 App 内「设置」页点「恢复初始数据」。卸载会清掉全部本地数据。
